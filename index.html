01 — Problem & Objectives

Why We Built This

⚠ Problem Statement

Traditional Engraving is Broken

Conventional manual engraving methods are slow, inconsistent, and require significant skilled labour — making them unsuitable for precision fabrication or small-batch production.

  • Time-consuming and error-prone manual processes
  • Commercial CNC engravers cost ₹50,000–₹5,00,000+
  • No user-friendly, affordable alternative exists
  • Limited material compatibility and customisation
✓ Our Solution

Low-Cost CNC Laser with GRBL

We designed and built a fully automated CNC laser engraver using Arduino, repurposed DVD stepper motors, and open-source GRBL firmware — delivering professional-grade output at a fraction of the commercial cost.

  • Automated G-code driven motion control
  • Customisable speed, power, resolution & passes
  • Engrave on wood, acrylic, plastic, and vinyl
  • Built for ₹5,300–₹11,100 using off-the-shelf parts
Objectives
OBJ 01

Design a low-cost, efficient laser engraving machine accessible for students and makers.

OBJ 02

Automate motion control using Arduino UNO + CNC Shield with TB6600 stepper drivers.

OBJ 03

Implement GRBL-based firmware for precise, repeatable G-code driven engraving.

OBJ 04

Build a user-friendly interface using LaserGRBL for design upload and live monitoring.

OBJ 05

Integrate a relay-based safety module for reliable laser power control and protection.

OBJ 06 ✓

All objectives successfully implemented, tested, and validated. Engraving trials complete.

05 — Firmware & Software

The Code That Drives It

📄 stepper_motor_control.ino — Arduino GRBL Motor Driver
// CNC Laser Engraver — Stepper Motor Control
// Final Year BE Project | Electronics & Telecommunication
// Team: Ashlesha Wagh, Snehal Kolte, Kaveri Uphade

#define M1_PUL  2    // X-axis pulse
#define M2_PUL  3    // Y-axis pulse
#define M1_DIR  5    // X-axis direction
#define M2_DIR  6    // Y-axis direction
#define M_ENA   8    // Motor enable (shared)
#define LED_PIN 13   // Status LED

int stepDelay   = 500;   // Microseconds (tune for speed)
int stepsPerRev = 200;   // Steps per revolution (1.8° motor)
int distance    = 20;    // Travel distance in step-sets

void setup() {
  pinMode(M1_PUL, OUTPUT); pinMode(M1_DIR, OUTPUT);
  pinMode(M2_PUL, OUTPUT); pinMode(M2_DIR, OUTPUT);
  pinMode(M_ENA,  OUTPUT); pinMode(LED_PIN, OUTPUT);
  delay(500);
  digitalWrite(M_ENA, HIGH); // Enable both TB6600 drivers
}

void loop() {
  // Move forward (X+ / Y+)
  digitalWrite(M1_DIR, HIGH); digitalWrite(M2_DIR, HIGH);
  rotateMotors(stepsPerRev, distance);
  delay(1000);

  // Move reverse (X- / Y-)
  digitalWrite(M1_DIR, LOW); digitalWrite(M2_DIR, LOW);
  rotateMotors(stepsPerRev, distance);
  delay(1000);
}

// Simultaneously drive both axis steppers
void rotateMotors(int steps, int travel) {
  for (int j = 0; j < travel; j++) {
    for (int i = 0; i < steps; i++) {
      digitalWrite(M1_PUL, HIGH); digitalWrite(M2_PUL, HIGH);
      delayMicroseconds(stepDelay);
      digitalWrite(M1_PUL, LOW);  digitalWrite(M2_PUL, LOW);
      delayMicroseconds(stepDelay);
    }
  }
}
📡
GRBL Firmware
Runs on Arduino UNO. Accepts G-code via USB serial at 115200 baud. Controls step/dir pins for both axes.
Firmware
🖼️
Image → G-Code
LaserGRBL converts any image format to G-code paths. Supports speed, power, resolution, and pass count tuning.
Software
🎛️
1/16 Microstepping
MS1-MS3 pins on TB6600 configured for 16th-step mode — 3200 steps/rev for smooth, low-noise motion.
